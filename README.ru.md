# PS5 Log Collector

[English](README.md) · [Русский](README.ru.md)

Портативное Windows-приложение для сбора KLOG и KStuff/game debug-вывода со взломанной PlayStation 5 — без Netcat и командной строки.

## Основные возможности

- Прямое TCP-подключение к `klog.elf` / `klogsrv`.
- Отдельная сессия Game DEBUG для [`ps5debug-NG` v1.3.0](https://github.com/OpenSourcereR-dev/ps5debug-NG).
- Режим KStuff Metrics для metrics-enabled `kstuff.elf` и `debug-reader.elf`.
- Встроенный раздел **SM+** для загрузки сохранённого `debug.log` из ShadowMountPlus.
- Сохранение соединения ELF-загрузчика после отправки для чтения stdout/stderr payload.
- Определение активной игры и запись структурированных trap/signal-событий с данными потока и регистров.
- Необязательная отправка выбранного пользователем ELF на активный загрузчик консоли через порт `9021`.
- Порт `3232` по умолчанию с возможностью изменения адреса и порта.
- Отзывчивый просмотр поступающего KLOG в реальном времени.
- ISO 8601 timestamp с миллисекундами и часовым поясом ПК для каждой строки.
- Сохранение полной сессии с момента установки соединения.
- Очистка видимого окна без остановки сбора; полную сессию по-прежнему можно сохранить.
- Сохранение незавершённой строки при остановке или разрыве соединения.
- Мгновенное переключение интерфейса между русским и английским языком.
- Запоминание выбранного языка, последнего адреса и порта.
- Один self-contained EXE: достаточно запустить файл, устанавливать .NET не требуется.
- Приложение не содержит и не запускает Netcat или Telnet.

Пример журнала:

```text
[2026-09-13T22:42:15.123+03:00] kernel: пример сообщения
```


## Требования

- Взломанная PlayStation 5 с возможностью запуска `klog.elf` или совместимого payload `klogsrv`.
- Для Game DEBUG дополнительно требуется запущенный на консоли `ps5debug-NG` v1.3.0.
- Компьютер и консоль должны находиться в одной локальной сети.
- Windows 11 x64 — основная поддерживаемая платформа.
- Windows 10 22H2 x64 — режим best-effort, совместимость следует проверять с актуальным релизом.

## Быстрый старт

1. Скачайте актуальный Windows EXE на странице [Releases](../../releases/latest).
2. Запустите `PS5LogCollector.exe`.
3. Выберите **KLOG**.
4. Введите IP-адрес консоли.
5. Активируйте `klog.elf` вручную либо выберите ELF и нажмите **Отправить на консоль**, пока совместимый загрузчик активен на порту `9021`.
6. Оставьте порт KLOG `3232`, если payload не настроен на другой порт, затем нажмите **Подключиться**.
7. Нажмите **Остановить**, чтобы завершить чтение, и **Сохранить журнал**, чтобы экспортировать полную сессию в UTF-8 текст.

Сохранение доступно и во время активного подключения. Отмена диалога сохранения не прерывает соединение и не удаляет накопленный журнал.

### Game DEBUG — KStuff Metrics

1. Выберите **DEBUG → KStuff Metrics** и введите IP-адрес консоли.
2. При необходимости выберите совместимый metrics-enabled `kstuff.elf` и отправьте его через загрузчик на порту `9021`.
3. Выберите `debug-reader.elf` и нажмите **Начать сбор метрик**.
4. Приложение отправит reader, закроет только направление загрузки и продолжит читать stdout/stderr по тому же соединению `9021`.
5. Перед остановкой payload нажмите **Остановить сбор**, затем сохраните полную сессию.

Reader выводит периодические снимки метрик kstuff, message/word logs, статистику syscall и ioctl-com. Для работы нужен соответствующий metrics-enabled вариант kstuff; приложение не может добавить метрики в обычную сборку kstuff.

### Game DEBUG — Debugger Events

Выберите **Debugger Events** для существующего режима `ps5debug-NG`: порт команд `744`, обратный канал событий `755` и структурированные trap/signal-пакеты. Это отдельный диагностический источник, не stdout KStuff Metrics.

KStuff Metrics собирает stdout/stderr payload reader, а не обычный stdout игры. Классический stdout приложения/SDK, вероятно, потребует DECI5 TTY и остаётся отдельным будущим транспортом. В v0.5.0 KLOG, DEBUG и SM+ работают отдельными сессиями.

### SM+ — ShadowMountPlus ([описание API](https://github.com/drakmor/ShadowMountPlus/blob/1.7/docs/api.md))

1. Откройте **SM+** в левом меню и введите IP-адрес PS5.
2. Нажмите **Забрать debug.log**. Сначала приложение проверит HTTP API ShadowMountPlus на порту `10101`.
3. Если API недоступен, раскройте запасной FTP-блок и укажите FTP-порт консоли (обычно `1337` или `2121`) и путь `/data/shadowmount/debug.log`.
   Поле пользователя FTP намеренно пустое по умолчанию; заполните его только если FTP-сервис консоли требует имя пользователя.
4. Проверьте загруженный файл и нажмите **Сохранить лог**, чтобы записать исходный текст без добавления timestamp или других строк.

Это одноразовая загрузка уже сохранённого файла; live-мониторинг ShadowMountPlus пока намеренно не добавляется. Обычно HTTP API доступен только на loopback, поэтому ShadowMountPlus нужно настроить на прослушивание локальной сети (например, `api_bind_address=0.0.0.0`). У API нет аутентификации, поэтому открывайте его только в доверенной локальной сети. API может вернуть только хвост слишком большого файла — статус окна сообщает об этом.


## Решение проблем с подключением

- **Подключение отклонено:** убедитесь, что `klog.elf` активен и слушает выбранный порт.
- **Истекло время подключения:** проверьте IP-адрес PS5, локальную сеть и правила брандмауэра.
- **Нет новых сообщений:** KLOG может молчать, пока консоль не создаёт новые сообщения ядра.
- **Соединение закрыто:** при необходимости перезапустите payload и подключитесь повторно.

Приложение использует тот же необработанный TCP-поток, что и команда:

```shell
nc <IP_PS5> 3232
```

Режим Telnet намеренно отсутствует: upstream-сервис предоставляет обычный TCP-сокет, а не протокол Telnet.

## Конфиденциальность и безопасность

KLOG и Game DEBUG могут содержать идентификаторы устройства и игры, имена потоков, адреса памяти, пути файловой системы, сетевые данные и другую диагностическую информацию. Проверяйте и при необходимости редактируйте журнал перед публичной публикацией.

PS5 Log Collector подключается только к адресу и портам, которые ввёл пользователь. Приложение не загружает логи в интернет, не содержит телеметрии и не выполняет jailbreak. Payload передаётся только после того, как пользователь сам выбрал локальный ELF и нажал **Отправить на консоль**.


## Архитектура

- `src/Ps5LogCollector.Core` — транспорт KLOG, загрузка ShadowMountPlus по HTTP/FTP, отправка ELF с чтением stdout по тому же сокету, протокол ps5debug-NG, жизненный цикл сессий, разбор событий, временный spool и полный экспорт.
- `src/Ps5LogCollector` — интерфейс WPF/Fluent, локализация, диалог сохранения и пользовательские настройки.
- `tests/Ps5LogCollector.Core.Tests` — независимые от сторонних пакетов тесты TCP, timestamps, разбора HTTP API ShadowMount, framing ps5debug-NG, разбора событий, detach, экспорта и совпадения локализаций.

Для производительности окно отображает ограниченную последнюю часть журнала, а временный spool сохраняет полную сессию для экспорта.
