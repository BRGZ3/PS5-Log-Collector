# PS5 Log Collector

[English](README.md) · [Русский](README.ru.md)

Портативное Windows-приложение для просмотра, добавления временных меток и сохранения журнала ядра со взломанной PlayStation 5 — без Netcat и командной строки.

> **Состояние проекта:** сбор KLOG доступен в версии `v0.1.1`. Поддержка DEBUG запланирована на будущее.

## Основные возможности

- Прямое TCP-подключение к `klog.elf` / `klogsrv`.
- Порт `3232` по умолчанию с возможностью изменения адреса и порта.
- Отзывчивый просмотр поступающего KLOG в реальном времени.
- ISO 8601 timestamp с миллисекундами и часовым поясом ПК для каждой строки.
- Сохранение полной сессии с момента установки соединения.
- Сохранение незавершённой строки при остановке или разрыве соединения.
- Мгновенное переключение интерфейса между русским и английским языком.
- Запоминание выбранного языка, последнего адреса и порта.
- Self-contained ZIP: достаточно распаковать архив и запустить приложение, устанавливать .NET не требуется.
- Приложение не содержит и не запускает Netcat или Telnet.

Пример журнала:

```text
[2026-09-13T22:42:15.123+03:00] kernel: пример сообщения
```


## Требования

- Взломанная PlayStation 5 с возможностью запуска `klog.elf` или совместимого payload `klogsrv`.
- Компьютер и консоль должны находиться в одной локальной сети.
- Windows 11 x64 — основная поддерживаемая платформа.
- Windows 10 22H2 x64 — режим best-effort, совместимость следует проверять с актуальным релизом.

## Быстрый старт

1. Скачайте актуальный Windows ZIP на странице [Releases](../../releases/latest).
2. Распакуйте архив в любую папку.
3. Запустите `PS5LogCollector.exe`.
4. Выберите **KLOG**.
5. Активируйте `klog.elf` на PS5.
6. Введите IP-адрес консоли. Оставьте порт `3232`, если payload не настроен на другой порт.
7. Нажмите **Подключиться**.
8. Нажмите **Остановить**, чтобы завершить чтение, и **Сохранить журнал**, чтобы экспортировать полную сессию в UTF-8 текст.

Сохранение доступно и во время активного подключения. Отмена диалога сохранения не прерывает соединение и не удаляет накопленный журнал.

## Решение проблем с подключением

- **Подключение отклонено:** убедитесь, что `klog.elf` активен и слушает выбранный порт.
- **Истекло время подключения:** проверьте IP-адрес PS5, локальную сеть и правила брандмауэра.
- **Нет новых сообщений:** KLOG может молчать, пока консоль не создаёт новые сообщения ядра.
- **Соединение закрыто:** при необходимости перезапустите payload и подключитесь повторно.

Приложение использует тот же необработанный TCP-поток, что и команда:

```shell
nc <IP_PS5> 3232
```

Режим Telnet намеренно отсутствует: upstream-сервис предоставляет обычный TCP-сокет, а не протокол Telnet.

## Конфиденциальность и безопасность

KLOG может содержать идентификаторы устройства, пути файловой системы, сетевые данные и другую диагностическую информацию. Проверяйте и при необходимости редактируйте журнал перед публичной публикацией.

PS5 Log Collector подключается только к адресу и порту, которые ввёл пользователь. Приложение не загружает логи в интернет, не содержит телеметрии, не изменяет консоль и не доставляет jailbreak payload.

## Сборка из исходного кода

Необходимо:

- .NET 10 SDK;
- Windows Desktop targeting pack.

```powershell
dotnet build Ps5LogCollector.slnx -c Release
dotnet run --project tests/Ps5LogCollector.Core.Tests -c Release
```

Создание self-contained ZIP для Windows x64:

```powershell
./scripts/publish-windows.ps1
```


## Архитектура

- `src/Ps5LogCollector.Core` — проверка endpoint, TCP-транспорт, жизненный цикл сессии, timestamps, UTF-8 декодирование, временный spool и полный экспорт.
- `src/Ps5LogCollector` — интерфейс WPF/Fluent, локализация, диалог сохранения и пользовательские настройки.
- `tests/Ps5LogCollector.Core.Tests` — независимый от сторонних пакетов набор regression-тестов TCP, timestamps, отмены, экспорта и совпадения локализаций.

Для производительности окно отображает ограниченную последнюю часть журнала, а временный spool сохраняет полную сессию для экспорта.
